## Rules

- A checkbox means implemented, tested, integrated, and verified.
- Tests are part of every feature.
- Do not mark a phase complete while required work is knowingly broken.
- Architecture changes must update DATABASE.md and the affected TODO.
- Prefer small, verifiable milestones.
- Phase completion requires every checkbox in that phase to be checked and its acceptance criteria to pass.
